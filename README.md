# Color Picker

A web-based Color Picker application inspired by the compact color picker layout in Google Search. Built with standard HTML, CSS, and vanilla JavaScript.

## Features

- **Interactive Visual Picker**: Pick saturation and value using a 2D interactive field, adjust hue with a slider, or select colors using the native browser color dialog or the EyeDropper API.
- **Multiple Color Formats**: Real-time conversion across HEX, RGB, HSL, HSV, and CMYK formats.
- **Direct Input & Copy**: Edit color channel values directly or copy formatted strings (e.g., `rgb(108, 92, 231)`) to your clipboard with one click.
- **Random Color Generator**: Quickly generate random colors.
- **Responsive Layout**: Designed for seamless use on both desktop and mobile devices.

## Usage

Since this project requires no build process or external dependencies, you can run it directly in any modern web browser:

1. Open `index.html` in your web browser.
2. Select or modify colors using the visual picker, sliders, or input fields.

## File Structure

- `index.html` - The HTML structure for the picker interface.
- `style.css` - Styling and layout definitions.
- `script.js` - Color space conversion logic, input handling, and UI updates.
